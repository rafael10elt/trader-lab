⚡ LUMI SENTINEL VISION

● site informativo — o sistema roda localmente

Este é o deploy estático do repositório. O Sentinel em si é um programa Python local: ele captura a tela do TradingView, lê o gráfico ao vivo (visão computacional), detecta o fechamento de cada vela, filtra a oportunidade com machine learning, confirma com a IA juiz (Groq) e, se houver setup, dispara alerta visual + sonoro na janela e no dashboard http://127.0.0.1:8777/.

Por que não é um site? O sistema precisa ler a tela da sua máquina — isso só existe onde o TradingView está aberto. Nada é enviado para a nuvem (exceto a imagem que você autoriza enviar à IA juiz da Groq para confirmação); o dashboard é servido localmente pelo próprio Python.

Como rodar

  1. Clone o repositório e entre na pasta:
git clone <seu-repo> && cd trader-lab
  1. Inicie (cria o venv e instala mss + pillow automaticamente):
sentinel\INICIAR_SENTINELA.bat

Ou, no terminal / VS Code, qualquer um destes funciona — o script se reabre sozinho no venv se você usar o Python do sistema:

python sentinel\sentinel.py
python sentinel\sentinel.py --check   # só diagnostica o ambiente

Primeira configuração (na GUI)

  1. 📈 Calibrar área do gráfico — arraste sobre as velas (sem o eixo de preços). É a única calibração;
  2. ▶️ Iniciar sentinela e abrir o dashboard;
  3. No dashboard, clique em Ativar som do alerta (libera o áudio do navegador).

Pipeline de decisão (a cada vela)

  1. Visão computacional extrai corpo/mechas/direção das velas;
  2. Filtro ML (regressão logística) pontua a chance de continuação — só passa acima do limiar (0.60);
  3. IA juiz (Groq) recebe a imagem + métricas e confirma ou rejeita o setup;
  4. Filtros de notícias, janela operacional e cooldown.

Machine learning que aprende sozinho

Cada sinal emitido é acompanhado: o Sentinel mede se o preço andou a favor ou contra e grava o resultado em data/treino.jsonl. Quando acumulam ≥30 exemplos novos, o modelo re-treina automaticamente. Comandos: ml.py status e ml.py treinar.

IA juiz (Groq)

Configure a chave GROQ_API_KEY (variável de ambiente ou config.json) e a IA passa a confirmar cada setup visualmente. Sem chave, o pipeline segue só com o ML.

Regras do setup

Tudo em sentinel/config.json: timeframe (1m…4h), limiar do ML, exigência de confirmação da IA, cooldown, filtro de notícias alto impacto USD/EUR, janela operacional e confirmação de gráfico vivo. Detalhes em sentinel/README.md.

⚠️ É um sinalizador, não um executor de ordens: ele avisa, a decisão e a execução continuam com você.
