⚡ LUMI SENTINEL VISION

● site informativo — o sistema roda localmente

Este é o deploy estático do repositório. O Sentinel em si é um programa Python local: ele captura a tela do TradingView, lê a célula de status (compra/venda), detecta o fechamento de cada vela e, se houver setup, dispara alerta visual + sonoro na janela e no dashboard http://127.0.0.1:8777/.

Por que não é um site? O sistema precisa ler a tela da sua máquina — isso só existe onde o TradingView está aberto. Nada é enviado para a nuvem; o dashboard é servido localmente pelo próprio Python.

Como rodar

  1. Clone o repositório e entre na pasta:
git clone <seu-repo> && cd trader-lab
  1. Inicie (cria o venv e instala mss + pillow automaticamente):
sentinel\INICIAR_SENTINELA.bat

Ou, no terminal / VS Code, qualquer um destes funciona — o script se reabre sozinho no venv se você usar o Python do sistema:

python sentinel\sentinel.py
python sentinel\sentinel.py --check   # só diagnostica o ambiente

Primeira configuração (na GUI)

  1. 🎯 Calibrar célula de status — arraste sobre o bloco ● AGUARDANDO... do TradingView;
  2. 📈 Calibrar área do gráfico (opcional) — habilita a tela ao vivo no dashboard e a confirmação de “gráfico vivo”;
  3. ▶️ Iniciar sentinela e abrir o dashboard;
  4. No dashboard, clique em Ativar som do alerta (libera o áudio do navegador).

Regras do setup

Tudo em sentinel/config.json: timeframe (1m…4h), estabilidade do gatilho, cooldown, filtro de notícias alto impacto USD/EUR, janela operacional e confirmação de gráfico vivo. Detalhes em sentinel/README.md.

⚠️ É um sinalizador, não um executor de ordens: ele avisa, a decisão e a execução continuam com você.
